# Positional Tactics - ターン制サッカーボードゲーム

チェスや将棋のようにポジショナルプレーの奥深さを体感できるターン制サッカーボードゲームです。
バックエンドに **C# (.NET 8 ASP.NET Core)**、フロントエンドに **React (TypeScript + Vite)** を採用し、1台の端末で2人のプレイヤーが交互に操作して対戦する「オフライン対戦」アプリケーションです。

---

## 🌟 主な特徴 & ゲームルール

1. **ポジショナル・ピッチ (縦10マス × 横5マス)**
   - 横5マスは「左サイド、左ハーフ、センター、右ハーフ、右サイド」の5レーン。
   - ゴールは縦両端（Row 0 および Row 11）のセンターレーン外側に配置。
2. **チーム構成 & コマの能力値**
   - 1チーム11名 ＋ ボール1個。
   - **能力3（エース/10番）**: 1名（ゴールドフレーム＆パルス発光オーラ、★★★）。
   - **能力2**: 3名（シルバーメタルフレーム、★★）。GK（背番号1）もここに含まれます。
   - **能力1**: 7名（シンプルなフレーム、★）。
   - **GK（ゴールキーパー）**: 特製シールド形状バッジ＆グローブアイコン（🧤）。
3. **1ターンのアクション (順序自由)**
   - **移動**: 最大2名まで、前後左右斜めに「最大2マス」移動（すり抜け可能、ドリブル移動含む）。
   - **パス / シュート**: ボール保持者が縦横斜めの直線状に無制限距離で出せます。ゴール枠へ向かうものは「シュート」になります。
   - **GK特権**: GKがボールを保持しているターンに限り、通常の2名移動・1回パスに加え、**「GK自身を追加で1回移動」**させることができます。
4. **特殊ルール & 判定ロジック**
   - **オフサイド**: パスが出た瞬間、受け手が「相手最後尾DF（GK除く）がいる横ライン」より相手ゴール側にいた場合オフサイド。ピッチ上に赤色のレーザー警告線がリアルタイム表示されます。
   - **サイコロ判定（デュエル）**:
     - **タックル**: 相手ボール保持マスに進入した瞬間に発生。
     - **パスカット / シュート阻止**: パス/シュートの直線経路上に相手がいる場合に発生。
     - **判定方法**: `(能力値合計 ＋ サイコロの目)` で勝負！数値が大きい側がボールを奪取（またはシュートでゴール）！
     - **3Dサイコロ演出**: 画面上でサイコロがダイナミックに回転する演出を実装。
5. **試合進行 & アディショナルタイム**
   - 前半45ターン、後半45ターン。
   - 45ターン終了時、サイコロ2個の合計値（2〜12）がアディショナルタイムとして追加されます。

## 🛠️ 技術スタック & アーキテクチャ

- **Backend**: C# (.NET 8 / ASP.NET Core Web API)
  - ルール判定（オフサイド、直線パス、タックル/パスカット判定、移動制限、アディショナルタイム）
  - 暗号論的乱数ジェネレーターによるサイコロ出目生成
  - ドメインモデルとサービスクラスの明確な責務分離
- **Frontend**: React 19 + TypeScript + Vite + Vanilla CSS (Design Tokens & Glassmorphism)
  - 10×5 ピッチ、レーンガイド、動的オフサイドライン、能力値別スタイリング、3Dサイコロ演出
- **Deployment**: Google Cloud Run (単一コンテナでフロントエンドSPAとバックエンドAPIを統合ホスト)
- **CI/CD**: GitHub Actions

## 🚀 ローカルでの開発・実行手順

### 前提条件
- .NET 8 SDK
- Node.js (v18以上) & npm

### 1. リポジトリのクローン
```bash
git clone https://github.com/<your-username>/FootballBoardGame.git
cd FootballBoardGame
```

### 2. バックエンド & フロントエンドの一括起動（推奨）
フロントエンドをビルドしてバックエンドから直接配信する場合：
```bash
# フロントエンドのビルド (wwwrootへ出力されます)
npm --prefix src/Client run build

# バックエンドの起動
dotnet run --project src/Server/FootballBoardGame.Server.csproj
```
ブラウザで `http://localhost:5281` を開くとゲームをプレイできます！

### 3. フロントエンド開発サーバー (HMR) を使った開発
```bash
# ターミナル1: バックエンドAPI
dotnet run --project src/Server/FootballBoardGame.Server.csproj

# ターミナル2: フロントエンド (Vite)
npm --prefix src/Client run dev
```
ブラウザで `http://localhost:5173` を開くとホットリロード付きで開発できます。
